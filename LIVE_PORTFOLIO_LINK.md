### **Option 1: GitHub Pages (Recommended - Takes 2 minutes)**

1. **Go to your repository settings:**

2. **Enable GitHub Pages:**

   - Click **Save**

3. **Wait 2-3 minutes, then your portfolio will be live at:**
   ```
   https://balamanoj07.github.io/fintrack/portfolio.html
   ```
